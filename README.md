# tools
A collection of tools I've made that I regularly use and want to access on several platforms


## imageExtractor
A shell script to extract icons from .appimage files and place them in ./icons<br>
Usage: imageExtractor ./{appname}.AppImage

## automake
Creates a super simple Makefile for C projects, taking in the main c file as an argument, and adding all .c files in the directory to be compiled<br>
Usage: automake [mainfile].c
